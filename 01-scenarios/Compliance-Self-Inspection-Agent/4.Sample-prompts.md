# Sample Prompts — Compliance Self-Inspection Agent

The **Compliance Self-Inspection Agent** is designed for one activity: starting a self-inspection of the signed-in employee's Outlook mail and OneDrive files. This guide provides one prompt for that workflow.

---

## How to Use This Prompt

1. Open the agent in **Microsoft Teams**, **Microsoft 365 Copilot**, or **Copilot Studio test chat**.
2. Enter the prompt below and complete any required connector sign-in using your own account.
3. Select the start and end dates on the adaptive card, within **1–180 days inclusive**, then select **Start self-inspection**.
4. Wait for both completion emails and open the result workbook using the provided link.

---

## Category 1: Starting a Self-Inspection

| # | Prompt | Expected Output |
|---|---|---|
| 1 | Start self-inspection | A date-selection card appears. After a valid date range is submitted, the agent starts inspecting the user's Outlook mail bodies, supported attachments, and OneDrive files. Completion emails link to the user's result workbook containing category keyword counts, numeric risk scores, and source links. |

### Example Interaction

The sequence below illustrates the workflow; status-message wording may vary.

> **User:** Start self-inspection
>
> **Agent:** Displays the date-selection card.
>
> **User action:** Selects a start date and end date, then submits the card.
>
> **Agent:** Acknowledges that the Outlook and OneDrive inspections have started.
>
> **Completion:** The user receives separate completion emails for the Outlook and OneDrive scans, with links to the result workbook.

**Started does not mean completed.** Wait for both scans to finish. The conversation provides status messages, not extracted document or email content.

---

## Scope

The workflow inspects both Outlook and OneDrive for the signed-in user. It is not designed as a general compliance Q&A assistant, a legal-advice service, or a file-editing tool, and it does not offer separate mailbox-only or OneDrive-only activities.

For sample files, expected keyword counts, and setup requirements, follow the [runbook](3.Runbook.md).
